# Odin 1.1.0

- Add opt-in isolated shell jobs with single-use handles, idempotent cancellation requests and typed completion acknowledgement.
- Keep legacy persistent-shell jobs and coroutine/Flow cancellation semantics unchanged.
- Terminate same-process-group descendants with TERM/KILL escalation, verify cleanup before completion, and quarantine uncertain transports. Deliberately detached descendants remain outside the guarantee.
- Add explicit root-availability invalidation and graceful fresh acquisition, with ROOT/NON_ROOT/BUSY/TIMED_OUT/FAILED observations.
- Bound shell startup across acquisition, handshake and initializers; publish only ready shells and clean up failed initialization resources. Custom initializer code must cooperate with interruption.
- Treat missing output completion markers as transport failure; drain failed readers and preserve synchronous scheduler progress on interruption.
- Add a reusable agent integration skill, Maven Local consumer-validation instructions, and build/unit/lint/API gates to the publishing workflow.

Isolated execution inherits cwd and exported environment, captures output to private temporary files and returns it at completion. State mutations and shell functions do not cross isolated jobs. A fresh control-shell acquisition with matching root identity and toybox setsid wait support are required before dispatch. Cancellation cannot roll back side effects or make an uncertain mutation safe to retry.
